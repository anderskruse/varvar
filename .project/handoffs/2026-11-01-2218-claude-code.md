## Gotchas
- The server rejects any Host header other than localhost; add forwarded hostnames (e.g. Codespaces ports) to allowed_hosts in ~/.project-hub/config.yaml
- Stop fires after every turn; the hook only blocks when the session changed files outside the note paths
- Handoff dates are local time with minute precision; file names sort newest first
- better-sqlite3 is a native module; if it fails to load the hub falls back to an in-memory cache and says so on stderr
